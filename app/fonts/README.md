# Шрифты

Geist и Geist Mono (Vercel, лицензия SIL Open Font License 1.1 — `OFL-LICENSE.txt`), версия из npm-пакета `geist@1.8.1`.

Файлы урезаны до диапазона символов `latin`, как у Google Fonts (`-latin.woff2`, ~33 КБ вместо ~70 КБ):
сайт англоязычный, кириллица и расширенная латиница не нужны. Если появится текст на других языках —
нужен новый урезанный файл с этими символами, иначе эти символы отрисуются запасным шрифтом.

Шрифты лежат в репозитории, а не скачиваются с Google при сборке: сборка не зависит от сети и всегда
даёт один и тот же результат.
