# Архитектурные решения (ADR)

ADR (Architecture Decision Record) — короткая запись об одном важном решении: что выбрали, почему, чем пожертвовали.
Пишется в момент решения, потом не переписывается. Если решение меняется — новая запись со ссылкой на старую.

Шаблон:

```
# NNNN. Название
Дата · Статус: принято / заменено NNNN

## Контекст      — какая проблема, какие ограничения
## Решение       — что выбрали
## Почему        — аргументы
## Компромиссы   — что теряем
## Пересмотреть, когда — при каких условиях решение устареет
```
