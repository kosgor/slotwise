# Этап 1: какие файлы созданы, зачем и как работают

Справочник по всем файлам, добавленным или изменённым на этапе 1. Порядок — как в дереве проекта.
Термины (Server Component, кэш, RLS и т.д.) объяснены в [cheatsheet.md](cheatsheet.md).

## Как всё связано (одна картинка)

```
Браузер → proxy.ts (чистый URL? профиль существует?)
        → app/(marketing)/…/page.tsx (страница, Server Component)
            → lib/catalog/repository.ts ("use cache" — кэш)
                → lib/catalog/source.ts (откуда данные: сейчас seed, потом Supabase)
                    → lib/catalog/seed-data.ts
            → components/features/… (карточки, фильтры) → components/ui/… (кнопки, поля)
        ← HTML (+ немного JS только для интерактивных частей)
```

## `app/` — страницы и служебные адреса

Next.js App Router: папка = часть URL, файл `page.tsx` = страница. Скобки `(marketing)` — группа,
в URL не попадает. Все страницы — Server Components, если в файле нет `"use client"`.

| Файл                                                                     | Зачем создан                                                    | Как работает                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/layout.tsx`                                                         | Общая обёртка **всех** страниц сайта                            | Рендерит `<html lang="en">` и `<body>`. Подключает шрифты через `next/font/local` (создают CSS-переменные `--font-sans`, `--font-mono`). Задаёт метаданные по умолчанию: шаблон заголовка `%s · Slotwise`, описание, `metadataBase` для абсолютных ссылок. Первой в `<body>` ставит ссылку «Skip to content» (видна только при фокусе с клавиатуры). Оборачивает всё в `Providers` (тема). Внизу выводит JSON-LD «Организация» и «Сайт» и лениво грузит контейнер уведомлений.                                                                                                                                                              |
| `app/globals.css`                                                        | Дизайн-токены и базовые стили                                   | `@import "tailwindcss"` подключает Tailwind v4. Блок `@theme inline` связывает классы Tailwind с переменными (`bg-primary` → `var(--primary)`). В `:root` — цвета светлой темы, в `.dark` — тёмной (класс `dark` на `<html>` ставит `next-themes`). Цвета в OKLCH. Внизу — CSS-анимация `.reveal`: появление блоков при прокрутке через `animation-timeline: view()`, только если браузер это поддерживает и пользователь не просил уменьшить движение.                                                                                                                                                                                     |
| `app/fonts/Geist-Variable-latin.woff2`, `GeistMono-Variable-latin.woff2` | Шрифты хранятся в проекте, а не скачиваются с Google при сборке | Вариативные шрифты (все толщины 100–900 в одном файле), урезанные до латиницы: ~33 КБ вместо ~70 КБ. `next/font/local` кладёт их в `/_next/static/media`, для Geist добавляет `<link rel="preload">`.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `app/fonts/OFL-LICENSE.txt`, `README.md`                                 | Лицензия шрифта и пояснение                                     | Лицензия SIL OFL требует распространять файл лицензии вместе со шрифтом. README объясняет, откуда шрифты и почему урезаны.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `app/(marketing)/layout.tsx`                                             | Шапка и подвал для публичной части                              | Рендерит `SiteHeader`, затем `<main id="main" tabIndex={-1}>` (сюда переносит фокус ссылка «Skip to content»), затем `SiteFooter`. Будущие кабинеты (`/account`, `/dashboard`) получат свои layout'ы.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `app/(marketing)/template.tsx`                                           | Анимация перехода между страницами                              | В отличие от `layout.tsx`, `template.tsx` пересоздаётся при каждой навигации — это и запускает анимацию. Просто оборачивает страницу в `PageTransition`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `app/(marketing)/page.tsx`                                               | Главная страница `/`                                            | Server Component. Параллельно (`Promise.all`) берёт из кэша статистику каталога и 3 лучших специалистов, собирает секции: Hero, «Как это работает», категории, лучшие, отзывы, FAQ, призыв к действию. Данные кэшированы, поэтому вся страница — готовый HTML при сборке (`○`).                                                                                                                                                                                                                                                                                                                                                             |
| `app/(marketing)/pros/page.tsx`                                          | Каталог `/pros` с фильтрами                                     | Страница делится на две части. Заголовок — статический, отдаётся мгновенно. `CatalogResults` читает `searchParams` (известны только при запросе), поэтому стоит внутри `<Suspense>` с заглушкой `CatalogSkeleton` и догружается потоком. `CatalogResults` разбирает URL (`parseCatalogQuery`), ищет (`searchProviders`), рендерит фильтры (десктоп — боковая панель, мобильный — выезжающая панель), счётчик «N professionals found» с `role="status"` (скринридер объявляет), чипы активных фильтров, сетку карточек или пустое состояние, пагинацию. `key={formKey}` пересоздаёт формы при смене URL, чтобы поля показали новые значения. |
| `app/(marketing)/pros/[slug]/page.tsx`                                   | Профиль специалиста `/pros/anna-yoga`                           | `[slug]` — динамическая часть URL. `generateStaticParams` возвращает все 24 slug — Next.js рендерит 24 HTML-файла при сборке. `generateMetadata` даёт каждой странице свой `<title>` и описание. Страница берёт данные (`getProviderBySlug`), при отсутствии вызывает `notFound()` (второй рубеж после `proxy.ts`). Рендерит: хлебные крошки, фото, о себе (`<dl>`), услуги с ценами и кнопкой «Book», отзывы, боковую карточку записи, JSON-LD «Person + услуги».                                                                                                                                                                          |
| `app/(marketing)/pros/[slug]/book/page.tsx`                              | Заглушка записи до этапа 2                                      | Проверяет, что специалист существует, показывает «Online booking is coming soon» и ссылку назад. `robots: { index: false }` — поисковикам не индексировать.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `app/(marketing)/pricing/page.tsx`                                       | Тарифы для специалистов                                         | Server Component с заголовком и вопросами про оплату. Интерактивную часть (переключатель месяц/год) рендерит клиентский `PricingPlans`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `app/(marketing)/design-system/page.tsx`                                 | Витрина дизайн-системы для ревьюеров                            | `"use cache"` — страница целиком кэшируется. Читает `globals.css` и считает контраст (`getContrastReport`), показывает цвета, таблицу контраста, типографику, все варианты кнопок, поля в состояниях норма/disabled/ошибка, бейджи, карточки, диалог, панель, вкладки, аккордеон, скелетоны, уведомления. `robots: noindex`, нет в навигации и sitemap.                                                                                                                                                                                                                                                                                     |
| `app/(marketing)/error.tsx`                                              | Страница «что-то сломалось»                                     | Обязан быть Client Component. Next.js показывает его, если при рендере страницы выпала ошибка. Пишет ошибку в консоль (до Sentry на этапе 5), показывает ID ошибки и кнопку «Try again» → `retry()` перерисовывает страницу.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `app/not-found.tsx`                                                      | Страница 404                                                    | Next.js показывает её при `notFound()` и для любых неизвестных адресов, включая перенаправление из `proxy.ts`. Ссылки «каталог» и «на главную».                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `app/sitemap.ts`                                                         | `/sitemap.xml` для поисковиков                                  | Возвращает массив адресов: главная, каталог, тарифы, все профили. Дата изменения берётся из данных, а не `new Date()` (Cache Components запрещает текущее время в пререндере). Next.js превращает массив в XML.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `app/robots.ts`                                                          | `/robots.txt`                                                   | Разрешает всё, кроме личных разделов (`/api`, `/account`, `/dashboard`, `/admin`, страницы записи). Отдельным правилом явно разрешает AI-краулеров. Указывает адрес sitemap.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `app/llms.txt/route.ts`                                                  | `/llms.txt` — описание сайта для языковых моделей               | Route Handler (`GET`), а не страница. Проходит по всем страницам каталога, собирает Markdown: описание сайта, главные страницы, список специалистов с ценами, FAQ. Отдаёт как `text/plain`.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `app/opengraph-image.tsx`                                                | Картинка-превью для ссылок в мессенджерах                       | Next.js при сборке рендерит JSX в PNG 1200×630 (`ImageResponse`) и автоматически добавляет `og:image` в `<head>`. CSS-переменные там недоступны, поэтому цвета бренда продублированы hex-кодами.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `app/page.tsx` (удалён)                                                  | —                                                               | Заглушка этапа 0 заменена лендингом в `(marketing)/page.tsx`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## `components/ui/` — базовые компоненты (shadcn)

Код, скопированный командой `npx shadcn add …`. Поведение (клавиатура, фокус, aria) даёт Radix,
внешний вид — Tailwind-классы с токенами. Это наш код, его можно менять.

| Файл                         | Зачем создан                                          | Как работает                                                                                                                                                                                                                     |
| ---------------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accordion.tsx`              | Раскрывающиеся блоки (показан на `/design-system`)    | Radix Accordion: стрелки и Enter управляют, закрытые панели убираются из DOM. Поэтому для FAQ на лендинге используется нативный `<details>`, а не он.                                                                            |
| `avatar.tsx`                 | Аватар shadcn (пока не используется в страницах)      | Radix Avatar: картинка с запасным содержимым. У нас свой `ProviderAvatar` на `next/image`.                                                                                                                                       |
| `checkbox.tsx`, `switch.tsx` | Флажок и переключатель                                | Radix: `role="checkbox"` / `role="switch"`, `aria-checked`, переключение пробелом. `switch` используется в тарифах.                                                                                                              |
| `dialog.tsx`                 | Модальное окно                                        | Radix Dialog: при открытии фокус уходит внутрь и не выходит наружу по Tab, Esc закрывает, фокус возвращается на кнопку-открыватель, фон блокируется.                                                                             |
| `sheet.tsx`                  | Выезжающая панель (мобильное меню, мобильные фильтры) | Тот же Radix Dialog, но выезжает с края экрана.                                                                                                                                                                                  |
| `label.tsx`                  | Подпись к полю                                        | `<label>` из Radix: клик по подписи фокусирует поле, скринридер читает подпись вместе с полем.                                                                                                                                   |
| `native-select.tsx`          | Нативный `<select>` в стиле дизайн-системы            | Обычный HTML `<select>` с нашими классами и иконкой стрелки. Работает без JS, на телефоне открывает системный выбор. Изменён шрифт: `text-base md:text-sm` (16px на телефоне, иначе iOS Safari увеличивает страницу при фокусе). |
| `select.tsx`                 | Выпадающий список Radix (показан на `/design-system`) | Рисует собственный список, нужен JS. Для фильтров не используется — там нативный.                                                                                                                                                |
| `skeleton.tsx`               | Серая заглушка-«скелет»                               | Блок с анимацией пульсации, показывается, пока грузятся результаты каталога.                                                                                                                                                     |
| `separator.tsx`              | Разделительная линия                                  | Установлен вместе с остальными, пока не используется.                                                                                                                                                                            |
| `sonner.tsx`                 | Всплывающие уведомления (тосты)                       | Обёртка над библиотекой `sonner`, берёт текущую тему из `next-themes`.                                                                                                                                                           |
| `tabs.tsx`                   | Вкладки                                               | Radix Tabs: стрелки переключают вкладки. Изменён цвет неактивной вкладки на `text-muted-foreground` — исходный не проходил проверку контраста axe.                                                                               |

## `components/layout/` — каркас сайта

| Файл                   | Зачем создан                                   | Как работает                                                                                                                                                                                                                                                                                              |
| ---------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `site-header.tsx`      | Шапка сайта                                    | Server Component. Липкая (`sticky top-0`) со **сплошным** фоном: полупрозрачный фон над бирюзовым блоком провалил проверку контраста. Содержит логотип, навигацию (на десктопе), переключатель темы, кнопку «Book a session», мобильное меню. Список пунктов `NAV_ITEMS` общий для десктопа и мобильного. |
| `nav-links.tsx`        | Ссылки навигации с подсветкой текущей страницы | Client Component: `usePathname()` узнаёт текущий адрес и ставит `aria-current="page"` активной ссылке (скринридер скажет «текущая страница»). Высота ссылок ≥ 44px — удобно попадать пальцем.                                                                                                             |
| `mobile-nav.tsx`       | Кнопка мобильного меню                         | Рисует только кнопку. Код самой панели (Radix Dialog, ~25 КБ) подгружается через `next/dynamic` — при наведении, фокусе или касании (заранее), отрисовывается по клику. `aria-expanded` сообщает скринридеру, открыто ли меню.                                                                            |
| `mobile-nav-sheet.tsx` | Сама панель мобильного меню                    | Загружается отдельным файлом по требованию. Так как кнопка-открыватель не внутри этого файла, фокус после закрытия возвращается на неё вручную (`onCloseAutoFocus`). Клик по ссылке закрывает меню.                                                                                                       |
| `site-footer.tsx`      | Подвал                                         | Server Component. Колонки: описание, категории (ссылки вида `/pros?category=yoga` — по ним роботы находят страницы категорий), разделы продукта. Год — константа: `new Date()` в пререндере запрещён.                                                                                                     |
| `logo.tsx`             | Логотип                                        | Ссылка на `/` с SVG-иконкой (`aria-hidden`, текст «Slotwise» читается) — цвет через `currentColor`, поэтому подстраивается под тему.                                                                                                                                                                      |
| `theme-toggle.tsx`     | Переключатель светлой и тёмной темы            | Client Component. Рендерит обе иконки, а видимость переключает CSS (`dark:hidden`) — поэтому HTML сервера и браузера совпадает, нет мигания. По клику `setTheme` из `next-themes` меняет класс на `<html>` и запоминает выбор.                                                                            |

## `components/features/` — компоненты предметной области

| Файл                           | Зачем создан                                  | Как работает                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------ | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `catalog/provider-card.tsx`    | Карточка специалиста в каталоге и на главной  | Server Component. Вся карточка кликабельна за счёт «растянутой» ссылки: у ссылки на имени псевдоэлемент `::after` закрывает всю карточку. Скринридер слышит одну ссылку с именем, а не весь текст карточки. Показывает фото, имя, заголовок, категорию, город, формат, рейтинг, «From $25».                                                                                                                        |

Если есть `photoUrl` — `next/image` фиксированного размера 48 или 80 px (браузер получает WebP 1x/2x, ~1–5 КБ). | `catalog/rating.tsx`           | «★ 4.8 (3 reviews)»                           | Звезда — декоративная (`aria-hidden`), смысл несёт текст. | `catalog/catalog-filters.tsx`  | Форма фильтров                                | Обычная GET-форма через `next/form`: при отправке значения полей становятся параметрами URL (`/pros?category=yoga`), без JS работает как HTML-форма, с JS — переход без перезагрузки. Перехватывает событие отправки до `next/form`, на мгновение отключает пустые поля и поля со значением по умолчанию (отключённые поля не попадают в данные формы), потом включает обратно. Результат: `/pros?category=yoga` вместо `/pros?q=&category=yoga&city=&…`.                                                                                                                                |
| `catalog/sort-select.tsx`      | Выбор сортировки                              | Client Component. Стоит вне формы, но атрибут `form="catalog-filters"` делает его частью формы — сортировка сохраняет фильтры. При изменении вызывает `form.requestSubmit()`.                                                                                                                                                                                                                                      |
| `catalog/mobile-filters.tsx`   | Фильтры на телефоне в выезжающей панели       | Client-обёртка только для состояния «открыто/закрыто». Саму форму рендерит сервер и передаёт как `children`. При отправке формы панель закрывается.                                                                                                                                                                                                                           |
| `catalog/active-filters.tsx`   | Чипы «Yoga ×», «Berlin ×»                     | Каждый чип — обычная ссылка на URL без этого фильтра. Для скринридера текст «Remove filter: Berlin».                                                                                                                                                                                                                                                                                                               |
| `catalog/pagination.tsx`       | Номера страниц                                | `<nav aria-label="Pagination">`, ссылки строятся через `catalogHref` и сохраняют фильтры, текущая страница с `aria-current="page"`. Неактивные стрелки — не ссылки.                                                                                                                                                                                                                                                |
| `landing/hero.tsx`             | Первый экран главной                          | Заголовок `h1` (элемент LCP — поэтому без анимации), поиск (GET-форма на `/pros?q=…`, `role="search"`), декоративное превью интерфейса записи с фото Анны (`aria-hidden`, загружается сразу через `preload`).                                                                                                                                                                                                      |
| `landing/sections.tsx`         | Остальные секции главной                      | «Как это работает» (нумерованный список), категории (ссылки в каталог), лучшие специалисты, отзывы (`<figure>`/`<blockquote>`), финальный призыв. | `landing/faq.tsx`              | Вопросы и ответы                              | Нативные `<details>`/`<summary>`: работает без JS, ответы есть в HTML для роботов. Рядом выводит JSON-LD `FAQPage` из тех же данных (`lib/content/faq.ts`). `id="faq"` — на него ведёт ссылка в меню.                                                                                                                                                                                                              |
| `pricing/pricing-plans.tsx`    | Карточки тарифов с переключателем             | Client Component с состоянием `monthly`/`yearly`. Для скринридера — одно объявление «Showing yearly prices».                                  |
| `design-system/toast-demo.tsx` | Кнопки показа уведомлений на `/design-system` | Client Component, вызывает `toast.success()` / `toast.error()` из `sonner`.                                                                                                                                                                                                                                                                                                                                        |

## Прочие компоненты

| Файл                                    | Зачем создан                                  | Как работает                                                                                                                                                                                                                                                                                |
| --------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `components/providers.tsx`              | Общие клиентские провайдеры                   | `ThemeProvider` из `next-themes` (тема из системы или выбора пользователя, класс на `<html>`) и `PageTransitionProvider`. Framer Motion сюда намеренно не включён.                                                                                                                          |
| `components/lazy-toaster.tsx`           | Контейнер уведомлений без утяжеления страницы | `next/dynamic` с `ssr: false`: код `sonner` грузится после показа страницы, а не в составе первого JS.                                                                                                                                                                                      |
| `components/motion/reveal.tsx`          | Появление блока при прокрутке                 | Server Component без JS: добавляет класс `.reveal` и CSS-переменную `--reveal-index` для небольшой задержки соседних блоков. Анимацию делает CSS из `globals.css`.                                                                                                                          |
| `components/motion/page-transition.tsx` | Плавное появление страницы при переходе       | Провайдер в корневом layout считает переходы (он не пересоздаётся), обёртка в `template.tsx` пересоздаётся. Первую загрузку не анимирует (не задерживать LCP), при `prefers-reduced-motion` — тоже. Анимация — встроенный в браузер Web Animations API (`element.animate`), без библиотеки. |
| `components/seo/json-ld.tsx`            | Вывод структурированных данных                | Рендерит `<script type="application/ld+json">` с текстом от `serializeJsonLd` (экранирует `<`, чтобы текст не закрыл тег — защита от XSS).                                                                                                                                                  |

## `lib/` — логика без интерфейса

| Файл                          | Зачем создан                                                | Как работает                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/catalog/types.ts`        | Типы данных каталога                                        | `Provider`, `Service`, `Review`, `ProviderSummary` (с минимальной ценой и рейтингом), `ProviderDetails` (с услугами и отзывами), список категорий и их названия. Поля совпадают с колонками SQL (camelCase ↔ snake_case).                                                                                                                                                                                                        |
| `lib/catalog/seed-data.ts`    | Демо-данные                                                 | 24 одобренных и 2 скрытых специалиста. Услуги собираются из шаблонов категорий × базовая ставка, отзывы — из набора фраз. Всё детерминировано (никакого `Math.random`) — одинаковые данные в приложении, тестах и `seed.sql`. Один отзыв скрыт — проверка модерации.                                                                                                                                                             |
| `lib/catalog/source.ts`       | Откуда берутся данные                                       | `loadApprovedSummaries()` и `loadProviderDetails(slug)`. Сейчас читают seed. На этапе 2 их тела заменятся запросами к Supabase — остальной код не изменится.                                                                                                                                                                                                                                                                     |
| `lib/catalog/repository.ts`   | Кэширование для страниц                                     | Каждая функция начинается с `"use cache"`: результат запоминается, аргументы — ключ кэша. `cacheLife("hours")` — срок жизни, `cacheTag("catalog")` — метка, по которой на этапе 2 кэш сбросится при изменении профиля. Страницы импортируют только этот файл.                                                                                                                                                                    |
| `lib/catalog/constants.ts`    | Константы без зависимостей                                  | Варианты сортировки, форматы, размер страницы и их подписи. Вынесены из `query.ts`, потому что клиентский `SortSelect` импортировал их оттуда и тянул в браузер Zod (+31 КБ).                                                                                                                                                                                                                                                    |
| `lib/catalog/query.ts`        | Логика поиска                                               | `parseCatalogQuery` — разбирает параметры URL через Zod; любое неверное значение превращается в «не задано» (`.catch`), страница не падает от ручной правки URL. `catalogHref` — строит URL обратно, без значений по умолчанию. `summarizeProviders` — только одобренные, мин. цена, средний рейтинг без скрытых отзывов. `filterProviders`, `sortProviders`, `paginate`, `searchCatalog` — чистые функции, всё покрыто тестами. |
| `lib/catalog/canonical.ts`    | Единственный правильный URL каталога                        | Разбирает параметры, строит канонический URL через `catalogHref`, посторонние параметры (`utm_source`) сохраняет. Возвращает `null`, если URL уже правильный.                                                                                                                                                                                                                                                                    |
| `lib/catalog/public-slugs.ts` | Быстрая проверка «такой профиль существует?» для `proxy.ts` | Сначала отсекает неверный формат slug (то же правило, что в SQL). Затем проверяет по списку одобренных slug, который хранится в памяти 60 секунд.                                                                                                                                                                                                                                                                                |
| `lib/catalog/format.ts`       | Форматирование для показа                                   | `formatPrice(4500)` → «£45» (пенсы → фунты через `Intl.NumberFormat`, `en-GB`), `formatDuration(90)` → «1 h 30 min», `startingPrice` → «From £25» или «Free intro», `formatsLabel`, `pluralize`.                                                                                                                                                                                                                                 |
| `lib/content/faq.ts`          | Тексты FAQ                                                  | Один массив для секции FAQ, JSON-LD `FAQPage` и `llms.txt` — тексты не расходятся.                                                                                                                                                                                                                                                                                                                                               |
| `lib/content/plans.ts`        | Тарифы Free и Pro                                           | Названия, цены в центах (месяц/год), список возможностей. На этапе 3 цены будут в Stripe.                                                                                                                                                                                                                                                                                                                                        |
| `lib/design/contrast.ts`      | Расчёт контраста по WCAG                                    | Переводит цвет OKLCH → линейный RGB → яркость, считает отношение контраста. `readCssVariables` достаёт переменные из блока CSS. `CONTRAST_PAIRS` — какие пары проверять и с каким порогом (4.5:1 для текста, 3:1 для границ полей и фокуса).                                                                                                                                                                                     |
| `lib/design/tokens.ts`        | Таблица контраста для `/design-system`                      | Читает `app/globals.css` при сборке и считает те же пары, что и тест.                                                                                                                                                                                                                                                                                                                                                            |
| `lib/seo/json-ld.ts`          | Структурированные данные schema.org                         | `serializeJsonLd` (безопасный вывод), `organizationJsonLd`, `websiteJsonLd` (с поиском по сайту), `faqJsonLd`, `providerJsonLd` (Person → Offer → Service, с фото и ценами).                                                                                                                                                                                                                                                     |
| `lib/site.ts`                 | Название, описание, адрес сайта                             | Адрес из `NEXT_PUBLIC_SITE_URL` (публичное значение) или `http://localhost:3000`. `absoluteUrl("/pros")` — полный адрес для sitemap, JSON-LD, Open Graph.                                                                                                                                                                                                                                                                        |

## Корень проекта, база данных, скрипты

| Файл                                                    | Зачем создан                                     | Как работает                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `proxy.ts`                                              | Код, который выполняется **до** рендера страницы | `matcher` — только `/pros`, `/pros/:slug`, `/pros/:slug/book`. Для `/pros`: если URL неканонический (пустые поля, мусор, другой порядок параметров) — редирект 308 на чистый. Для профилей: если slug неизвестен или специалист не опубликован — внутреннее перенаправление на несуществующий адрес, Next.js отдаёт страницу 404 с кодом 404. На этапе 2 сюда добавится обновление сессии Supabase.                                                                                                                       |
| `playwright.config.ts`                                  | Настройки e2e-тестов                             | Два «устройства»: Desktop Chrome и Pixel 7. Перед тестами поднимает продакшен-сервер `next start` на порту 3100 (тестируется то, что получит пользователь, а не dev-режим).                                                                                                                                                                                                                                                                                                                                               |
| `supabase/migrations/20261016000000_catalog.sql`        | Схема каталога для Supabase                      | Типы-перечисления (статус, категория), таблицы `providers`, `services`, `reviews` с проверками (цена ≥ 0, рейтинг 1–5, slug только из `a-z0-9-`, хотя бы один формат), индексы, триггер `updated_at`. Включает RLS на всех таблицах и политики «читать могут все — только одобренных специалистов, активные услуги, нескрытые отзывы». Политик на запись нет — писать может только сервер. Представление `catalog_providers` с минимальной ценой и рейтингом, `security_invoker = true` — чтобы RLS работал и через него. |
| `supabase/migrations/20261017000000_provider_photo.sql` | Колонка фото                                     | Добавляет `photo_url` (только путь `/…` или `https://…` — защита от `javascript:`). Пересоздаёт представление с новой колонкой в конце и **повторяет** `security_invoker` (иначе опция сбрасывается — проверено). Новая миграция, а не правка старой: применённые миграции не меняют.                                                                                                                                                                                                                                     |
| `supabase/seed.sql`                                     | Демо-данные для базы                             | Сгенерирован, руками не править. `INSERT` всех специалистов, услуг, отзывов.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `scripts/generate-seed.mts`                             | Генератор `seed.sql`                             | `npm run db:seed`. Импортирует `seed-data.ts`, экранирует кавычки, пишет SQL. CI проверяет, что `seed.sql` не устарел.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `public/images/providers/*.jpg`                         | Фото трёх специалистов                           | Unsplash (бесплатная лицензия), 640×640. Браузер их напрямую не получает — только уменьшенные копии через `/_next/image`.                                                                                                                                                                                                                                                                                                                                                                                                 |
| `package.json`                                          | Зависимости и команды                            | Добавлены `motion` (Framer Motion), `next-themes` (тема), `zod` (валидация URL), `sonner` (уведомления), `tw-animate-css` (анимации открытия диалогов shadcn); для разработки — `@playwright/test`, `@axe-core/playwright`, `@electric-sql/pglite`. Команды `test:e2e`, `db:seed`; `typecheck` запускает `next typegen` (генерирует типы маршрутов) перед `tsc`.                                                                                                                                                          |
| `tsconfig.json`                                         | Настройки TypeScript                             | Добавлено `allowImportingTsExtensions` — скрипту генерации seed нужно импортировать `.ts` с расширением (Node запускает TypeScript напрямую).                                                                                                                                                                                                                                                                                                                                                                             |
| `vitest.config.mts`                                     | Настройки unit-тестов                            | `resolve.tsconfigPaths` — понимает `@/…`. Запускает `tests/unit` и `tests/rls`, окружение jsdom (имитация браузера).                                                                                                                                                                                                                                                                                                                                                                                                      |
| `.github/workflows/ci.yml`                              | Проверки на каждый PR (заработают после пуша)    | Задача `checks`: типы, линтер, формат, unit + RLS-тесты, проверка актуальности `seed.sql`. Задача `e2e`: ставит Chromium, собирает приложение, гоняет Playwright; при падении сохраняет трассы.                                                                                                                                                                                                                                                                                                                           |
| `.gitignore`                                            | Что не попадает в git                            | Добавлены служебный кэш Supabase CLI и отчёты Playwright.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
